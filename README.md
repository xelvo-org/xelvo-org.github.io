# Xelvo

This repository hosts the public website for Xelvo Media Player, an Android app for playing local video and music.

## Links

- [Xelvo website](https://xelvo-org.github.io/)
- [Privacy Policy](https://xelvo-org.github.io/privacy.html)
- [Terms of Use](https://xelvo-org.github.io/terms.html)
- [Support](https://xelvo-org.github.io/support.html)
- [Open-source notices and release materials](https://github.com/xelvo-org/xelvo-open-source/releases)

The website is static and does not require server-side services.

The Google Play graphic in `assets/google-play-lockup.png` is provided by Google and is used only to link to Xelvo's Google Play listing. Other site assets are owned by Xelvo unless stated otherwise.
